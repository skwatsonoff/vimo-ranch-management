# VIMO voice models
Files the VIMO app downloads to understand speech on the phone itself
(transformers.js, 8-bit ONNX). Built by .github/workflows/voice-model-build.yml
on the main branch from Apache-2.0 models:
- whisper-tamil-small: vasista22/whisper-tamil-small (SPRING Lab, IIT Madras)
- whisper-tamil-base: mahimairaja/whisper-base-tamil
scores.json: how well each heard the owner's own recordings.
