## 2. கண்டுபிடித்த பிழை (மைக் அனுமதி கொடுத்தும் கேட்கவில்லை)

பழைய code-இல் (`75a3f7f`) இந்தப் பிரச்சினைகள் இருந்தன:

1. **Tap இல்லாமல் தொடக்கம்:** திரை திறந்தவுடன் tap இல்லாமலேயே மைக் தொடங்கப்பட்டது. அனுமதி சோதனை, TTS அமைப்பு, மாடல் சோதனை எல்லாம் முடிந்த பிறகுதான் `AudioContext` timer-இலிருந்து உருவானது. iPhone Safari அந்த ஒலியை tap வரும்வரை நிறுத்தி வைக்கும். அனுமதி மட்டும் சோதிக்கப்பட்டது; மைக் track உடனே நிறுத்தப்பட்டது.
   **Chromium-இல் மறுஉருவாக்கம்:** Safari போன்ற கொள்கையை அமைத்து ஓட்டியபோது, பழைய `vimoEar.start()` `ERR audio suspended` என்று தோற்றது.
2. **மாடல் பதிவிறக்கம் முடியும்வரை எதுவும் நடக்காது:** Tamil மாடல் cache-இல் இல்லையென்றால் “பதிவிறக்கு (290 MB)” அட்டை மட்டும் வந்தது. அனுமதி கொடுத்திருந்தாலும் கேட்பது தொடங்கவில்லை.
3. **செத்துப்போன stream மீண்டும் பயன்பாடு:** அழைப்பு அல்லது வேறு app மைக் track-ஐ முடித்த பிறகும், பழைய `openMic()` (`if (stream) return;`) அதே பழைய stream-ஐப் பயன்படுத்தி “listening” என்று காட்டியது.
   **Chromium-இல் மறுஉருவாக்கம்:** track நிலை `ended` ஆக இருந்தும் restart `listening` என்று காட்டியது; புதிய getUserMedia அழைப்பு நடக்கவில்லை.

**இன்னும் சரிபார்க்க வேண்டியது:** உண்மையான iPhone 14 Pro Max-இல் இவை ஒவ்வொன்றும் எந்த வரிசையில் நடக்கின்றன என்பது சோதிக்கப்படவில்லை. என்னிடம் iPhone இல்லை; WebKit browser-உம் இங்கே நிறுவப்படவில்லை.

## 3. என்ன மாற்றப்பட்டது

- **`web/vimo_mic.js`:** மைக்குக்கு ஒரே உரிமையாளர், ஒவ்வொரு தொடக்கத்துக்கும் தனி generation எண். `AudioContext` உருவாக்குவதும் getUserMedia அழைப்பதும் tap நடக்கும் அதே கணத்தில் நடக்கின்றன.
  - உண்மையான audio frames வந்த பிறகே “listening” காட்டப்படும். 4 வினாடிக்குள் வராவிட்டால் watchdog பிழை சொல்லும்.
  - AudioWorklet பயன்படும்; அது இல்லாத browser-இல் ScriptProcessor மாற்றுவழி.
  - கீழ்க்கண்ட எதுவும் நடந்தால் capture முழுவதும் நின்று buffer அழிக்கப்படும்: audioSession interrupted, track mute/ended, context interrupted/suspended, page hidden, pagehide, Bluetooth/route change.
  - நிறுத்திய பிறகு தாமதமாக வரும் stream உடனே நிறுத்தப்படும்.
  - எதுவும் சேமிக்கப்படாது.
- **`lib/voice_capture.dart`:** தனித்தனி நிலைகள் கொண்ட state machine: idle, connecting, needsTap, listening, processing, speaking, paused, interrupted, error, stopped. பழைய generation-இலிருந்து வரும் ASR அல்லது Gemini பதில் கைவிடப்படும்.
- **குரல் திரை (iPhone web):** “கேட்கத் தொடங்கு” tap இல்லாமல் மைக் திறக்காது.
  - Safari இன்னும் ஒரு tap கேட்டால் “கேட்கத் தொடங்கத் தட்டுங்கள்” என்று காட்டும்.
  - இடைநிறுத்தம் நடந்தால் “குரல் பதிவு இடைநிறுத்தப்பட்டது — மைக் வேறு பயன்பாட்டில் இருக்கலாம்” என்று காட்டி, “மீண்டும் கேள்” tap-க்காகக் காத்திருக்கும்.
  - ஒவ்வொரு அட்டையிலும் “கையால் பதிவு” பொத்தான் இருக்கும்.
  - VIMO பேசும்போது மைக் உள்ளீடு அடைக்கப்படும்.
- **Phone-இல் AI சேமிப்பு நிறுத்தம்:**
  - 290 MB மாடல் பதிவிறக்கம் நீக்கப்பட்டது.
  - புதிய Hive lesson-களோ பதிவுகளோ phone-இல் எழுதப்படாது.
  - Draft-இல் கேட்ட வாக்கியம் இனி சேமிக்கப்படாது.
  - Diagnostics log-இல் வாக்கியங்களுக்குப் பதிலாக அவற்றின் நீளம் மட்டும் இருக்கும்.
  - “Download for offline voice” மெனுவிலிருந்து மறைக்கப்பட்டது.
  - பழைய மாடல் cache-ஐயும் பழைய பதிவுகளையும் நீங்கள் கேட்டால் மட்டுமே நீக்கலாம்.
- **Bridge v2 (`tools/voice_bridge`):**
  - Access code நீக்கப்பட்டது. அதற்குப் பதிலாக Firebase ID token, Firestore விதிகள் வழியாக ranch உறுப்பினர் சோதனை, `drive.file` அனுமதி.
  - Gemini: kill switch உண்டு; ஒவ்வொரு அழைப்புக்கும் முன் billing அணைந்திருக்கிறதா எனச் சோதனை; quota முன்பதிவு; C1/C2 tokens; v2 schema இரு பக்கமும் சரிபார்க்கப்படும்.
  - கற்றல்: ஒப்புதல் தேவை; மாற்ற முடியாத, நகல் இல்லாத உதாரணங்கள்; குரல் மாதிரிக்குத் தனி ஒப்புதல்.
  - தினசரி alias கற்றல்: குறைந்தது இரண்டு உறுதிப்படுத்தல்கள் தேவை; முரண்பாடுகள் தனியே பிரிக்கப்படும்; regression gate; checksum உள்ள manifest.
  - “என் தரவை நீக்கு” வசதி.
- **Parser:** “செவ்வாள” போன்ற ஒலியொத்த பெயருக்கு இரண்டு மாடுகள் பொருந்தினால், ஒன்றைத் தானே தேர்ந்தெடுக்காமல் கேட்கும். `cowRivalScore = .85`; உண்மைத் தரவைக் கொண்டு மீண்டும் சீரமைக்க வேண்டும்.
- **`services/vimo-asr`:** VIMO-வின் தனிப்பட்ட speech-to-text சேவை. Code-உம் tests-உம் தயார். **Host இன்னும் தேர்வு செய்யப்படவில்லை.**

## 6. நீங்கள் எடுக்க வேண்டிய ஒரு முடிவு: ASR host

தமிழ்ப் பேச்சை எழுத்தாக்க ஒரு சர்வர் தேவை. அது ₹0 ஆக இருக்க வேண்டும், card இருக்கக்கூடாது, தானாக கட்டணத்துக்கு மாறக்கூடாது. Google Apps Script-ஆல் இதைச் செய்ய முடியாது. ஒரு வழி: **Hugging Face Spaces — free CPU, private Space**. இதைப் பயன்படுத்தினால் உங்கள் ஒலி Hugging Face சர்வரில் நினைவகத்தில் மட்டும் செயலாக்கப்படும். நீங்கள் ஒப்புக்கொண்டால், அடுத்த அமர்வில் அமைத்து WER அளவிட்டு அறிக்கை தருவேன். அதுவரை iPhone-இல் குரல் “அமைக்கப்படவில்லை” என்று காட்டி கையால் பதிவைத் திறக்கும்.

   - ASR host இல்லாததால் இப்போது “குரல் அறிதல் இன்னும் அமைக்கப்படவில்லை” என்ற அட்டையும் **கையால் பதிவு** பொத்தானும் தெரிய வேண்டும். அதுதான் சரியான நடத்தை.
2. **மைக் அனுமதியை மாற்ற:** Safari-இல் முகவரிக்கு அருகில் **aA (அல்லது ⋯) → Website Settings → Microphone → Allow**. எல்லாத் தளங்களுக்கும் அல்லது Home Screen app-க்கு: **Settings → Apps → Safari → Microphone → Ask/Allow**.
3. **Google Drive இணைக்க:** `tools/voice_bridge/README.md` படிகள் 1–8 (Apps Script-இல் Code.gs ஒட்டுதல், `setupVimoFolder` ஓட்டுதல், Deploy). பிறகு VIMO-வில் **Settings → VIMO குரல் → Google Drive இணை**.
4. **கற்றல் ஒப்புதல்:** VIMO குரல் திரையில் “என் திருத்தங்களிலிருந்து கற்றுக்கொள்” இயக்குங்கள். “குரல் மாதிரிகள்” switch தனியானது, இயல்பாக அணைந்திருக்கும். குடும்பத்தில் ஒவ்வொருவரும் தங்கள் குரலுக்குத் தாமே முடிவு செய்ய வேண்டும்.
5. **Gemini (விருப்பம்):** README பகுதி 2-இன்படி key-ஐ Apps Script Script properties-இல் மட்டும் வையுங்கள். Chat-இல் ஒருபோதும் ஒட்ட வேண்டாம். பிறகு VIMO குரல் திரையில் Gemini switch.
6. **அழைப்புச் சோதனை (ASR host வந்த பிறகு):**
   1. VIMO-வில் கேட்கத் தொடங்குங்கள்.
   2. இன்னொரு phone-இலிருந்து அழைத்து, பதில் சொல்லி, பிறகு துண்டியுங்கள்.
   3. VIMO-வுக்குத் திரும்புங்கள். “குரல் பதிவு இடைநிறுத்தப்பட்டது” என்று தெரிய வேண்டும்; எந்தப் புதிய பதிவும் வந்திருக்கக்கூடாது.
   4. **மீண்டும் கேள்** தட்டுங்கள்.
   5. இதையே Safari-இலும் Home Screen app-இலும் செய்யுங்கள்.

   **Web-இல் சாத்தியமில்லாதது:** அது phone அழைப்புதான் என்று browser உறுதியாகச் சொல்ல முடியாது. அதனால் VIMO பொதுவான இடைநிறுத்தச் செய்தியையே காட்டும்.
7. Preview திருப்தியாக இருந்தால் PR-ஐ merge செய்ய ஒப்புதல் தாருங்கள். Merge ஆனதும் production தானாக deploy ஆகும்.
